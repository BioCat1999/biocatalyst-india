# App permissions — Biocatalyst India

This audit describes version 1.0.0 as built from Expo SDK 54 and checked from
the final signed Android App Bundle with Bundletool 1.18.3.

## Android manifest

The final bundle declares:

- `android.permission.INTERNET` — required to load catalyst data and perform
  account actions against the HTTPS API.
- `android.permission.VIBRATE` — a normal, non-runtime Android capability
  included by the React Native/Expo dependency graph.
- `android.permission.USE_BIOMETRIC` and `USE_FINGERPRINT` — included by
  `expo-secure-store` so the OS can protect the local session credential.
- The package-scoped `DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION` generated by
  AndroidX. It cannot be granted to other applications.

None of these creates an in-app runtime permission prompt in version 1.0.0.
The app does not declare `POST_NOTIFICATIONS`, camera, microphone, location,
contacts, calendar, broad storage access, advertising ID, phone state,
Bluetooth, or background-location permissions.

`app.json` explicitly blocks legacy external-storage permissions and
`SYSTEM_ALERT_WINDOW` during manifest merging. The store-readiness test also
guards against accidentally adding camera, microphone, location, contacts,
or calendar declarations.

## iOS

Version 1.0.0 does not include notification, camera, microphone, location,
contacts, calendar, photo-library, or background-mode capabilities. It needs
no privacy usage-description prompt. The signed-in session token is held by
`expo-secure-store` in the platform credential store.

## Deferred features

Remote push delivery is not implemented in the first release. The previous
notification toggle and native notification dependency were removed so the
store submission does not request a permission for an unfinished feature.
Adding push later requires a new permission audit, updated privacy disclosure,
FCM/APNs credentials, and an end-to-end delivery test before release.

## Release checks

- Run the mobile Jest store-readiness suite.
- Validate the `.aab` with Bundletool.
- Dump the final bundle manifest and compare its permissions with this file.
- Revisit Play Data safety after every native dependency change.
